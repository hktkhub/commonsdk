# 错误码编码规则

## 码位结构

| 码类型 | 位数 | 组成 | 示例 |
|---|---|---|---|
| 本地码 `Code` | 5 | 2 位模块号 + 3 位模块内序号 | `30043` |
| 完整码 `FullCode` | 12 | 7 位前缀（业务线 + 服务，当前预留未注入）+ 5 位本地码 | `000000030043` |

## 取值规则

| 项 | 规则 |
|---|---|
| 生成 | `base.NewCode(module, errcode)` = `module*1000 + errcode` |
| 模块号范围 | `0–99` |
| 序号范围 | `0–999`，模块内独立从 1 递增 |
| 越界处理 | 直接 `panic` |
| 未指定 | `CodeUnset = -1` |
| 输出格式 | 定长补零：本地码 5 位、完整码 12 位 |
| 对外契约 | `base.Error` = `error` + `Code() Code` |

## 模块规则

| 模块 | 编号 | 层级 | 收录判据 |
|---|---|---|---|
| HTTP | 0 | 标准 HTTP 语义 | 永久保留，错误码位即 HTTP 状态码（404 → `00404`），业务不得占用 |
| Common | 1 | 通用/框架层 | 与业务域无关、全模块通用；描述中不出现业务名词 |
| Auth | 2 | 准入/安全层 | 决定“请求能否被允许”（401/403、令牌、验证码、scope、风控） |
| Business | 3 | 业务规则层 | 由业务规则触发、用户可理解且理论上可纠正 |
| Runtime | 4 | 运行/系统层 | 来自系统或外部依赖、用户不可纠正，前 3 层兜底 |

## 分配约定

| 项 | 规则 |
|---|---|
| 新增顺序 | 先按判据定层级，再在对应文件末尾追加序号 |
| 文件划分 | 一模块一文件：`common.go` / `auth.go` / `business.go` / `runtime.go` |
| 禁止 | 跨层混放；复用其他模块序号；占用模块 0 |
| 命名 | 变量前缀与模块语义一致：`Common*` / `Auth*` / `Billing*`·`Quota*`·`Tenant*` / `Runtime*` |
